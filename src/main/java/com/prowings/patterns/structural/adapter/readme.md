🎯 Scenario:
Imagine your new smartphone only supports USB-C input, but your old charger has a micro-USB plug.
You don’t want to buy a new charger — so what do you do?
✅ You use a USB-C adapter that fits over your micro-USB plug.


🔧 Design Pattern Mapping:
Component	Real-world Equivalent

Target	New USB-C port (expected by phone)

Adaptee	Old charger with micro-USB

Adapter	USB-C adapter (micro-USB to USB-C)

Client	The phone
